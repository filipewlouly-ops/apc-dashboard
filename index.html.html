☁️ Configurar Sincronização em Nuvem

Siga o passo a passo abaixo para hospedar o dashboard online e compartilhar com a equipe. É gratuito e não requer instalação de nenhum programa.

1
Criar conta no JSONBin.io (banco de dados gratuito)
  1. Acesse jsonbin.io e clique em Sign Up
  2. Crie uma conta gratuita (pode usar o Google)
  3. Após entrar, clique no seu avatar (canto superior direito) → API Keys
  4. Copie a Master Key (começa com $2b$...)
2
Criar o "Bin" (onde os dados serão salvos)
  1. No JSONBin, clique em + New Bin
  2. Cole o seguinte JSON inicial e clique em Create Bin:
{"lessons":[],"schedules":[]}

Após criar, a URL ficará assim: https://api.jsonbin.io/v3/b/SEU_BIN_ID — copie o ID

3
Inserir as credenciais no Dashboard

Cole sua Master Key e o Bin ID nos campos abaixo e clique em Salvar e Conectar. Isso será feito apenas uma vez por dispositivo.

4
Hospedar o arquivo no GitHub Pages (opcional, para acesso via link)
  1. Crie uma conta gratuita em github.com
  2. Clique em New repository → dê um nome (ex: apc-dashboard) → Create repository
  3. Clique em uploading an existing file, faça upload do arquivo apc-dashboard.html e renomeie para index.html
  4. Clique em Commit changes
  5. Vá em Settings → Pages, em Source selecione main e clique em Save
  6. Aguarde ~2 minutos. O link será: https://SEU-USUARIO.github.io/apc-dashboard/
  7. Compartilhe esse link com todos os servidores da equipe 🎉
⚠
Importante: cada membro da equipe precisa inserir as credenciais

As credenciais ficam salvas apenas no navegador local de cada pessoa. Cada servidor que acessar o dashboard deverá repetir o Passo 3 uma única vez no seu dispositivo. Depois disso, todos verão e editarão os mesmos dados em tempo real.

✅ Como funciona depois de configurado
  • Ao abrir o dashboard, os dados são carregados automaticamente do JSONBin
  • Ao salvar qualquer edição, os dados são enviados para a nuvem imediatamente
  • Qualquer pessoa com o link e as credenciais vê as informações atualizadas
  • O plano gratuito suporta até 10.000 requisições/mês e arquivos até 100KB — mais que suficiente
